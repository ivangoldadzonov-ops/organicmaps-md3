# Дизайн-система Organic Maps MD3

Система построена на трёх правилах Material Design 3:

1. **Тональные поверхности.** Иерархия строится цветом поверхности, а не тенью. Тень остаётся только у плавающих элементов: FAB, поисковой строки, баннера манёвра.
2. **Роли, а не оттенки.** Компонент использует `primary`, `primary-container`, `on-primary-container`, а не «зелёный №3». Смена темы не меняет разметку.
3. **Плотность Pixel.** Метрики кратны 4, минимальная цель касания 48 dp, радиусы 8–28 dp.

Источник правды — `tokens/tokens.json`. CSS-зеркало — `tokens/css/tokens.css`, платформенные обёртки — `android/`, `qt/`.

## Цветовые роли

Палитра светлой темы сгенерирована из исходного бренд-зелёного Organic Maps (`#146C43`) по алгоритму MD3 tonal palette: primary — тон 40, primary-container — тон 90, on-primary-container — тон 10.

| Роль | Светлая | Тёмная | Где применяется |
|---|---|---|---|
| `primary` | `#146C43` | `#8BD6A5` | FAB «моё местоположение», активная вкладка, кнопка «Маршрут», баннер манёвра |
| `on-primary` | `#FFFFFF` | `#003920` | Текст и иконки на primary |
| `primary-container` | `#A6F2C1` | `#00522F` | Тональный FAB, чип «Еда», фон кнопки «Офлайн-карта» |
| `on-primary-container` | `#00210F` | `#A6F2C1` | Текст на primary-container |
| `secondary` | `#4E6355` | `#B4CCBA` | Индикатор выбранной элемента навигации |
| `secondary-container` | `#D0E8D6` | `#364B3D` | Пилюля активной вкладки нижней навигации, выбранный вариант маршрута |
| `tertiary` | `#3A6470` | `#A2CDDC` | Акценты карты: вода, POI-кафе, рейтинг |
| `tertiary-container` | `#BEEAF8` | `#214C58` | Плашки POI-кафе и воды |
| `error` | `#BA1A1A` | `#FFB4AB` | Только ошибки и удаление, не для POI |
| `surface` | `#F7FBF5` | `#0F1511` | Фон экрана, фон карты под подписями |
| `surface-container-low` | `#F1F5EF` | `#171D18` | Нижний лист (основной фон панелей) |
| `surface-container` | `#EBEFE9` | `#1B211C` | Нижняя навигация, карточки-группы в настройках |
| `surface-container-high` | `#E5E9E4` | `#252B26` | Поисковая строка, чипы поверх карты, сегментированный переключатель |
| `surface-container-highest` | `#E0E4DE` | `#303631` | Тональные FAB, дорожка переключателя |
| `outline` | `#717971` | `#8A938B` | Контур невыключенного переключателя |
| `outline-variant` | `#C0C9C0` | `#414942` | Разделители, границы чипов, ручка листа |
| `on-surface-variant` | `#414942` | `#C0C9C0` | Вторичный текст, подписи, иконки в покое |

Правила:

- Контраст текст/фон не ниже 4.5:1, крупный текст — 3:1. Пары выше проверены.
- `primary` никогда не используется как фон большой площади: только акцент и главное действие.
- Цвет не единственный носитель смысла: выбранный вариант маршрута дополнительно выделен рамкой, «открыто» — словом.

## Типографика

Шрифт — Roboto (Android, веб) и Roboto на десктопе через Qt. Вариативный вес не используется: 400 для чтения, 500 для акцентов.

| Стиль | Размер / интерлиньяж | Вес | Применение |
|---|---|---|---|
| headline-medium | 28 / 36 | 400 | Заголовок «Настройки» |
| headline-small | 24 / 32 | 400 | Название места в нижнем листе |
| title-large | 22 / 28 | 500 | «Рядом с вами», «12 мин» в ETA |
| title-medium | 16 / 24 | 500 | Название POI в списках |
| body-large | 16 / 24 | 400 | Плейсхолдер поиска, строки настроек |
| body-medium | 14 / 20 | 400 | Адреса, описание, отзывы |
| body-small | 12 / 16 | 400 | Метаданные: расстояние, категория |
| label-large | 14 / 20 | 500 | Кнопки, чипы, вкладки навигации |
| label-medium | 12 / 16 | 500 | Подписи нижней навигации, бейджи |

Правило для карты: подписи улиц — 11–12 px с обводкой цветом поверхности (`paint-order: stroke`) для читаемости на любом фоне.

| Токен | Значение | Компоненты |
|---|---|---|
| extraSmall | 4 dp | Индикаторы, мелкие бейджи |
| small | 8 dp | Чипы фильтров |
| medium | 12 dp | Малые FAB, превью места, элементы альтернатив |
| large | 16 dp | FAB, карточки-строки, кнопки-контейнеры |

## Elevation

| Уровень | Тень | Компоненты |
|---|---|---|
| 0 | нет | Карта, нижний лист, навигация |
| 1 | `0 1px 2px / 0 1px 3px` | Чипы поверх карты, зум-кластер, выбранный сегмент |
| 2 | `... 0 2px 6px` | Поисковая строка, FAB, карточка результата |
| 3 | `... 0 4px 8px` | Баннер манёвра (единственное место с крупной тенью) |

Нижний лист намеренно без тени: он отделён скруглением и сменой тона поверхности. Тень поверх карты — единственный способ показать «плавает», поэтому она там сохраняется.

## Motion

| Токен | Значение | Применение |
|---|---|---|
| easingEmphasized | `cubic-bezier(0.2, 0, 0, 1)` | Разворачивание листа, переключатели |
| easingStandard | `cubic-bezier(0.2, 0, 0, 1)` | Смена темы, наведение |
| durationShort4 | 200 ms | Микро-состояния |
| durationMedium2 | 300 ms | Смена экрана, тема |
| durationLong2 | 500 ms | Лист на весь экран |

Все анимации отключаются при `prefers-reduced-motion: reduce`. Пульсация «моё местоположение» — единственная декоративная анимация, период 2.8 с.

## Доступность

- Цель касания ≥ 48×48 dp; нижняя навигация — 80 dp с иконкой 64×32 dp.
- Иконки без текста имеют `aria-label`.
- Переключатели — `role="switch"` с `aria-checked`.
- Фокус виден: 2 dp кольцо `primary` вокруг поля поиска.
- Все тексты проверены на контраст в обеих темах; `on-surface-variant` на `surface-container-high` даёт 5.1:1.
- Смысл не кодируется только цветом: открыто/закрыто — словом, выбранный маршрут — рамкой.
