# Экраны

Пять экранов покрывают основной сценарий: найти место, посмотреть его, построить маршрут, настроить приложение.

## 1. Карта

**Задача:** ответить «где я и что рядом» за один взгляд.

Снизу вверх:

1. Нижняя навигация — 80 dp, всегда на месте.
2. Поисковая строка — прямо над навигацией, в зоне большого пальца: до неё достаёт одна рука.
3. Карта — чистая поверхность без плавающих категорий: приглушённая палитра (парки `#CDE8C4`, вода `#B6DEF5`, дороги белые с песочной обводкой), цветная заливка только у значимых объектов.
4. Правый нижний угол над поиском: слои, компас, «моё местоположение» (primary FAB).
5. Левый нижний угол над поиском: зум.

**Решения:**

- Поиск внизу — главный вход в сценарий; верх экрана остаётся карте.
- Быстрые категории («Еда», «Кафе», «АЗС», «Отели») живут на экране «Поиск», а не поверх карты: карта не перекрывается и остаётся читаемой.
- Тональные FAB вместо белых кружков — меньше визуального шума на светлой карте.
- На карте нет листа «Рядом»: ближайшие места показывает поиск, поэтому карта занимает всю высоту.

## 2. Навигация

**Задача:** вести по маршруту, не отвлекая.

- Баннер манёвра `primary` наверху: расстояние крупно, инструкция мелко, следующий манёвр — справа.
- Бейджи: время прибытия, текущая скорость, звук.
- Лист снизу: ETA крупно, расстояние и время прибытия, закрытие маршрута.
- Сегменты транспорта остаются доступны во время движения — переключение пересчитывает маршрут.
- Альтернативы: три варианта, выбранный выделен тонально и рамкой.
- Действия: скачать офлайн-карту, поделиться маршрутом.

**Решения:**

- Маршрут на карте — `primary` 8 dp с ореолом 16 dp и прозрачностью 18%: виден на любом фоне.
- Точка старта — круг с обводкой цвета поверхности, чтобы не сливаться с линией.
- Скорость показывается только при движении: в пробке цифра не прыгает.
- Нет отдельного экрана «Маршрут» до старта: параметры задаются здесь же, сегментами и альтернативами.

## 3. Поиск

**Задача:** найти конкретное место за минимум тапов.

- Поле ввода в app bar, кнопка «назад» возвращает на карту.
- Быстрые категории: «Еда», «Кафе», «АЗС», «Отели» — перенесены сюда с карты.
- Фильтры OSM: «Открыто», «Рядом», «Wi-Fi», «Оплата картой».
- «Лучший результат» — крупная карточка с превью, часами работы, расстоянием и кнопкой маршрута.
- Остальное — компактный список с иконкой категории, типом заведения, расстоянием и доступными удобствами.
- Нижняя навигация сохраняется: поиск не тупик.

**Решения:**

- Один лучший результат вместо однородного списка: пользователь чаще всего едет в первое место.
- Метаданные — только нативные для OpenStreetMap: часы работы, дистанция, тип заведения, Wi-Fi и оплата картой. Рейтингов, звёзд и отзывов нет, потому что в OSM их нет.
- История запросов не показана намеренно: приложение приватное по умолчанию, история хранится локально и открывается отдельным действием.

## 4. Карточка места

**Задача:** решить «идти или нет» и сразу начать маршрут.

- Верх — карта-герой 320 dp, затем лист от 268 dp.
- Заголовок, категория, кухня и статус работы — без рейтинга и числа отзывов.
- Четыре быстрых действия: маршрут (заполненная иконка), звонок, сохранение, шеринг.
- Информационная карточка: адрес, часы, кухня, Wi-Fi, оплата картой, сайт, телефон.
- Закреплённая кнопка «Построить маршрут» внизу.

**Решения:**

- Карта остаётся видимой сверху — место в контексте города, а не абстрактная карточка.
- Быстрые действия — иконки с подписями: узнаваемость выше, чем у чистых иконок.
- Кнопка маршрута дублируется: в быстрых действиях для тех, кто листает вверх, и внизу для тех, кто дочитал.
- Часы работы — текстом, без сложной таблицы: на мобильном это читается быстрее.
- Метаданные берутся из OSM-тегов (`opening_hours`, `cuisine`, `internet_access`, `payment:cards`): рейтинги и отзывы не показываются.

## 5. Настройки

**Задача:** предсказуемо управлять картами, навигацией и приватностью.

- Крупный заголовок, поиск по настройкам в правом верхнем углу.
- «Внешний вид»: сегменты темы + крупный шрифт на карте.
- «Карты»: скачанные регионы с прогрессом, слои, автообновление.
- «Навигация»: платные дороги, голос.
- «Приватность»: бейдж «Без трекеров», история поиска.
- «О приложении»: версия, помощь проекту.

**Решения:**

- Тема переключается сегментами, а не списком: видно все три варианта сразу.
- Прогресс скачивания — кольцо в строке, без отдельного экрана.
- Приватность — отдельная группа с положительным бейджем: это ценность продукта, а не юридический раздел.
- Настройки сгруппированы в карточки с заголовками `primary` — сканирование по цвету быстрее, чем по тексту.

## Общая сетка

- Поля 16 dp по краям, 20 dp внутри листов и карточек с текстом.
- Расстояние между группами — 16 dp, между карточкой и заголовком группы — 8 dp.
- Нижняя навигация всегда 80 dp; контент никогда не уходит под неё.
- Все экраны работают в светлой и тёмной темах без изменения структуры.
