# Компоненты

Каждый компонент описан в терминах токенов. Имена классов совпадают с прототипом (`prototype/styles.css`).

## Поисковая строка (search bar)

```
[иконка меню] [подпись-плейсхолдер]            [аватар]
```

- Высота 56 dp, радиус 28 dp, фон `surface-container-high`, elevation 2.
- Плейсхолдер: `body-large`, `on-surface-variant`.
- Тап по строке открывает экран поиска; меню слева — вход в закладки и профиль.
- В режиме ввода превращается в `search-field`: высота 48 dp, кнопка «назад» слева, поле с кольцом фокуса 2 dp `primary`.
- Состояния: покой, наведение (`surface-container-highest`), фокус (кольцо), ввод.

## Чип фильтра (filter chip)

- Высота 32 dp, радиус 8 dp, `label-large`.
- Покой: фон `surface-container-high`, границы нет, иконка + текст.
- Выбран: `secondary-container` / `on-secondary-container`; иконка меняется на галочку в Android-версии, в прототипе остаётся категорийной.
- Поверх карты — elevation 1; в потоке экрана — граница `outline-variant` и фон `surface`.
- Горизонтальная прокрутка, крайний чип не обрезается отступом 16 dp.

## Нижняя навигация (navigation bar)

- Высота 80 dp, 5 пунктов, фон `surface-container` (в листе — тот же, лист просвечивает).
- Активный пункт: пилюля 64×32 dp `secondary-container`, иконка `on-secondary-container`, подпись `on-secondary-container`.
- Неактивный: `on-surface-variant`, без пилюли.
- Иконки 24 dp внутри пилюли, отступ сверху 12 dp, подпись `label-medium`.
- Правило: пунктов всегда 5, «Ещё» — последний и ведёт в настройки.

## FAB

| Вариант | Размер | Фон | Где |
|---|---|---|---|
| primary | 56 dp, радиус 16 | `primary` / `on-primary` | «Моё местоположение» |
| tonal small | 40 dp, радиус 12 | `surface-container-highest` | Слои, компас, звук |
| filled small | 40 dp | `primary` | Завершить маршрут |

FAB стоит справа, на 16 dp от края и на 12 dp выше нижнего листа. Стек FAB выравнивается по правому краю, расстояние между кнопками 10 dp.

## Нижний лист (bottom sheet)

- Радиус 28 dp сверху, фон `surface-container-low`, без тени.
- Ручка: 32×4 dp, `outline-variant`, отступ 4 dp сверху и 10 dp снизу.
- Три состояния: peek (заголовок + 3 строки + навигация), expanded (контент + прокрутка), cover (от 268 dp от верха, для карточки места).
- Внутренние отступы: 20 dp по горизонтали для текста, 8–12 dp для строк-списков.
- Лист не перекрывает FAB: FAB смещается вверх на высоту листа.

## Строка места (place row)

```
(40) [иконка POI]  Название            Открыто до 23:00
                   Категория · 320 м · Открыто
```

- Высота 60 dp, радиус 16 dp, hover `surface-container`.
- Иконка POI: круг 40 dp, `tertiary-container` для кафе, `primary-container` для еды, `secondary-container` для парков.
- Название `body-large` 500, метаданные `body-small` `on-surface-variant`.
- «Открыто» — `primary` 500; «Закрыто» — `error`.

## Карточка результата (result card)

- Ширина экрана минус 32 dp, фон `surface-container`, радиус 16 dp, отступ 12 dp.
- Превью 88×88 dp, радиус 12 dp, тональный фон категории.
- Справа кнопка-иконка «Маршрут» 40 dp, `primary-container`.
- Заголовок `title-medium`, метаданные `body-small`: тип заведения, расстояние, часы работы и удобства из OSM в одной строке.

## Сегментированный переключатель (segmented button)

- Контейнер: радиус full, фон `surface-container-high`, отступ 3 dp.
- Сегмент: высота 36 dp, радиус full, `label-large`.
- Активен: `surface-container-lowest` + elevation 1 + `on-surface`.
- 4 сегмента для видов транспорта, 3 — для темы.

## Переключатель (switch)

- 52×32 dp, дорожка `surface-container-highest`, контур 2 dp `outline`.
- Выключен: ползунок 16 dp `outline` слева.
- Включён: дорожка и контур `primary`, ползунок 24 dp `on-primary` справа.
- Анимация 300 ms `emphasized`; ползунок растёт при переключении — как в Android 14.

## Баннер манёвра (maneuver banner)

- Радиус 28 dp, фон `primary`, текст `on-primary`, elevation 3.
- Слева иконка манёвра 32 dp, по центру: расстояние `title-large`, инструкция `body-small` с прозрачностью 86%.
- Справа блок «затем» с разделителем 1 dp `rgba(255,255,255,.28)`.
- Обновляется на расстоянии 300 / 150 / 50 м; на последних 50 м фон меняется на `tertiary` (решение: цвет = срочность).

## Значок скорости

- 44 dp высоты, радиус full, `inverse-surface` / `inverse-on-surface`.
- Число 18 px 500, единица 10 px с прозрачностью 70%.
- Показывается только при скорости выше 5 км/ч.

## Панель ETA

```
12 мин                                  [x]
4,2 км · прибытие в 9:53
```

- `headline-medium` для времени, `body-medium` для деталей.
- Кнопка закрытия 44 dp, `primary` / `on-primary`.

## Строка альтернативы маршрута

- Радиус 12 dp, отступ 10/12 dp.
- Выбранная: `secondary-container` + рамка 1 dp `secondary`.
- Формат: `4,2 км` (`title-medium`) · `12 мин` (`body-small`) · тег · цена.

## Карточка-группа настроек

- Радиус 28 dp, фон `surface-container`, отступ 8 dp.
- Внутри — строки 12 dp с радиусом 16 dp, разделители не нужны.
- Заголовок группы — `label-large` `primary`, 20 dp от края.

## Кнопки

| Тип | Высота | Фон | Применение |
|---|---|---|---|
| filled | 56 dp (full-width) / 44 dp | `primary` | «Построить маршрут» |
| tonal | 44 dp | `secondary-container` | «Офлайн-карта» |
| text | 44 dp | прозрачный | «Поделиться», «Все» |

Радиус — full. Горизонтальные отступы 20 dp. Две кнопки в ряду: тональная занимает свободное место, текстовая — по контенту.

## Точка «моё местоположение»

- Точка 7 dp `primary` с обводкой 2.5 dp цвета поверхности.
- Два пульсирующих круга: 13 dp (22% прозрачности) и 26 dp (14%), период 2.8 с.
- При навигации точка смещается к нижней трети экрана, карта следует за ней.
